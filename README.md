7-Zip Forensics Demo - `7zip_app`

Overview:
This workspace contains simple demos showing common forensic tasks using 7-Zip on Windows:
- Compress files with encryption (`demo_compress`)
- List archive contents (`demo_list`)
- Compute file hashes (`demo_hash`)
- Extract archives (`demo_extract`)
- Search archives for filenames (`demo_search`)

Prerequisites:
- Windows with 7-Zip installed. Ensure `7z` is on PATH or set the `7ZIP` environment variable to the full path of `7z.exe`.

Quick start:
Open a Command Prompt in this folder and run:

```
run_all_demos.bat
```

See each demo folder for details.
