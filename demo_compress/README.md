Demo: Compression with 7-Zip

Files:
- `compress.bat` - Creates `sample.7z` from files in `sample_files`.
- `sample_files/` - Example input files.

Usage:
Open Command Prompt in this folder and run:
```
compress.bat
```
This creates `sample.7z` in the same folder. To change the source or output, pass arguments: `compress.bat <source_dir> <out_archive>`.
